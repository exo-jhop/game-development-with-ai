# Lesson 2.1 Exercise: Game Analysis

## Overview

In this exercise, you'll analyze three games you already know using the vocabulary from the guide. Then you'll use that vocabulary to write a prompt for a brand-new game idea.

This is how game designers think — they break down what works, understand *why* it works, and use that understanding to create something new.

---

## Instructions

1. Pick three games you've played (any platform — mobile, console, PC, board games all count)
2. For each game, fill in the analysis sections below
3. After analyzing all three, write an AI prompt for a new game idea that borrows elements from your analyses

---

## Example Analysis: Super Mario Bros.

**Game Title:** Super Mario Bros.

**Genre:** 2D Platformer

**Core Mechanics:**
- Move left/right
- Jump (variable height based on button hold)
- Run (hold button to move faster and jump farther)
- Stomp enemies by landing on them
- Collect coins and power-ups
- Break blocks from below

**Player Verbs:** Move, run, jump, stomp, collect, break

**Game Loop:**
- *Micro loop:* Jump between platforms, avoid or stomp enemies, collect coins
- *Core loop:* Start at the beginning of a level, navigate to the flagpole at the end, advance to the next level
- *Meta loop:* Progress through 8 worlds, each with 4 levels, to rescue the princess

**What Makes It Fun (Aesthetics):**
- Challenge — Precise jumping feels rewarding
- Discovery — Hidden blocks and secret paths reward exploration
- Sensation — Satisfying sound effects and responsive controls

## Reflection

After writing your prompt, ask yourself:
- [ ] Did I name the genre?
- [ ] Did I list the player verbs?
- [ ] Did I describe the micro and core loops?
- [ ] Did I say what feeling the game should create?
- [ ] Could someone who has never heard my idea build it from this prompt alone?

If you answered yes to all five, your game design vocabulary is working.
