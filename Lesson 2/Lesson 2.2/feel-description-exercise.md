# Lesson 2.2 Exercise: Describing Game Feel

## Overview

In this exercise, you'll practice translating the *feeling* of games into precise vocabulary that AI can act on. You'll analyze how three games feel, then write AI prompts that could recreate those feelings.

---

## Instructions

1. Pick three games with distinctly different feels (for example: a fast-paced action game, a slow exploration game, and a tight platformer)
2. For each game, describe how it feels using vocabulary from the guide
3. Write an AI prompt that captures each game's feel for a new game
