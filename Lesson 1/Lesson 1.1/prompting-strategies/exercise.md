# Exercise: Choose Your Tool, Write Your Prompt

## Instructions

For each scenario below:
1. **Pick the right tool** — code tool (OpenCode/Claude) or asset tool (Gemini/Google Flow)
2. **Write the prompt you would actually send** — not a summary, the real prompt
3. **Explain in one sentence why you chose that tool**

There are no trick questions. Some may feel obvious — that's fine. The goal is to build the habit of stopping to think "what tool, what prompt?" before you start typing.

## When You're Done

Review your prompts. Check each one against these criteria:
- [ ] Does it name the engine? (for code prompts, mention Godot 4)
- [ ] Does it describe what you want specifically, not vaguely?
- [ ] Is it asking for one thing, not five?
- [ ] Would someone reading it know exactly what you expect back?
- [ ] If it's a bug, does it describe the symptom — and include the exact error text, if Godot showed one?
