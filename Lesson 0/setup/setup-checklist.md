# Lesson 0 — Pre-Work Setup Checklist

Before Lesson 1 begins, every student needs a working toolchain. This is pure logistics — installing software and confirming accounts work. It is **not** a Godot tutorial: students will click exactly four things in Godot (Import → select folder → Import & Edit → Play) and nothing else. No node inspector, no scene tree, no code.

Do this the session before Lesson 1, or as take-home prep. Budget 20–30 minutes.

---

## 1. Install Godot 4

- [ ] Download **Godot 4.x** (the standard, non-.NET build) from [godotengine.org](https://godotengine.org/download)
- [ ] Extract/install it and launch it once to confirm it opens

**Why Godot 4 specifically:** the whole course pins AI prompts to Godot 4.x syntax (see the lock-in line in Lesson 1.1). Godot 3 projects will not match anything in this course.

---

## 2. Get Access to a Code AI Tool

Pick **at least one**:

- [ ] **Claude** — [claude.ai](https://claude.ai) account, or Claude Code if your instructor provides setup instructions
- [ ] **OpenCode** — install and confirm it runs a basic prompt

**Verify it works:** send it one test prompt (e.g. "Say hello") and confirm you get a response.

---

## 3. Get Access to an Asset AI Tool

Pick **at least one**:

- [ ] **Gemini** (Google AI Studio or the Gemini app) — confirm you can generate an image
- [ ] **Google Flow** — confirm account access

**Verify it works:** generate one throwaway test image.

---

## 4. Create a GitHub Account

- [ ] Sign up at [github.com](https://github.com) if you don't already have an account
- [ ] Confirm you can log in

You'll use this starting in Lesson 1.3 to commit your work as portfolio evidence. No git commands need to be memorized in advance — AI will direct the commit process when the time comes.

---

## 5. Download and Open the Starter Template

- [ ] Download the **course starter template** (provided by your instructor)
- [ ] Open Godot 4 → **Import** → navigate to the starter template folder → select `project.godot` → **Import & Edit**
- [ ] Press **F5** (or the Play button) and confirm a window opens showing a placeholder scene

If the Play button doesn't do anything, or an error appears, flag it now — this confirms your Godot install works before Lesson 1 depends on it.

**That's the full extent of the engine interaction for this checklist.** You do not need to know what you're looking at inside the editor. The template's structure is fixed and documented for AI — you'll never need to open, edit, or explain it yourself.

---

## 6. Confirm File Management Basics

- [ ] You know where the starter template folder lives on your computer
- [ ] You can rename a file and move a file between folders

This is the only "computer literacy" requirement for the course — no programming background needed.

---

## Setup Complete?

If every box above is checked, you're ready for **Lesson 1.1: Prompting Strategies for Game Dev**.

**Stuck on something?** Describe the symptom (what happened, what you expected) to your instructor the same way you'll learn to describe bugs to AI in Lesson 1.2 — that's good practice early.
